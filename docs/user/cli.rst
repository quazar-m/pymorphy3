.. _cli:

==========================
Работа из командной строки
==========================

.. important:: Для работы из командной строки нужен Click. Установите его
   вместе с pymorphy3 командой ``pip install pymorphy3[CLI]``.

Вместе с пакетом устанавливается утилита ``pymorphy``::

    pymorphy parse [options] [<input>]
    pymorphy dict meta [--lang <lang> | --dict <path>]
    pymorphy dict mem_usage [--lang <lang> | --dict <path>] [--verbose]
    pymorphy -h | --help
    pymorphy --version

Разбор текста
-------------

Команда ``pymorphy parse`` читает текст из файла (или из stdin, если файл
не указан) и пишет разборы слов в stdout::

    pymorphy parse -t -l -s text.txt

Опции:

``--dict <path>``
    путь к папке со словарём.

``--lang <lang>``
    язык словаря; допустимые значения: ``ru``, ``uk`` (по умолчанию ``ru``).

``-l``, ``--lemmatize``
    включать в вывод нормальные формы (леммы).

``-s``, ``--score``
    включать в вывод оценку P(tag|word).

``-t``, ``--tag``
    включать в вывод теги.

``--tokenized``
    считать, что текст уже токенизирован: один токен на строку.

``-c``, ``--cache <SIZE>``
    размер кэша в записях; ``0`` - отключить кэш, ``unlim`` - кэш без
    ограничения размера (по умолчанию 20000).

``--thresh <NUM>``
    отбрасывать разборы, у которых оценка P(tag|word) меньше порога
    (по умолчанию 0.0).

Если не указана ни одна из опций ``-l``, ``-s``, ``-t``, то включены все три.

Информация о словаре
--------------------

Команда ``pymorphy dict meta`` показывает метаданные словаря::

    pymorphy dict meta --lang ru

Команда ``pymorphy dict mem_usage`` показывает, сколько памяти занимает
словарь и сколько времени он загружается; с опцией ``-v`` вывод более
подробный::

    pymorphy dict mem_usage --lang ru -v
